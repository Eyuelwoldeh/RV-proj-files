# Raspberry Pi-Powered Car Project

Welcome to my Raspberry Pi-powered car project! This is a personal exploration of robotics, 3D printing, and embedded systems. I'm designing and printing my own parts using **OpenSCAD** while documenting my progress along the way.

---

## Project Goals

- Build a fully functional car controlled by a Raspberry Pi.
- Design and 3D print all custom parts using **OpenSCAD**.
- Experiment with motor control, sensors, and software automation.
- Share my learning process and improvements over time.

---

## 🛠️ Tech Stack

- **Hardware:** Raspberry Pi (Model TBD), DC motors, servo steering, sensors.
- **3D Modeling:** OpenSCAD.
- **Programming:** Python (for control logic), possibly C++ for performance.
- **Electronics:** Motor drivers, batteries, sensors (TBD).

---
